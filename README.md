# Yallah Habibi 🤙

> **"Vibe-coder. The person behind that tiny footer text."**  
> *No degree, no bootcamp, no fear. Just a prompt, a dream, and a suspicious number of open tabs.*

A satirical, neo-brutalist interactive micro-portfolio / landing page celebrating the art of vibe-coding, shipping at 2 AM, and prompt engineering over stack traces.

---

## ✨ Features & Easter Eggs

- **Shy "Don't Hire Me" Button**: Good luck trying to click or hover over it — it flees and judges you.
- **Interactive Bug Squashing**: A rogue `🐛` crawling across the viewport. Squash it to rack up your debug stats.
- **Confetti Cannon (`Hire me`)**: Emoji bursts when you consider making the right choice.
- **Vibe-o-Matic Estimator**: Real-time satirical project estimation engine.
- **Team Roster**: Credit where credit's due — Claude, Gemini, ChatGPT, Replit, and Coffee (the only one on the payroll).
- **Konami Code**: Hit `↑ ↑ ↓ ↓ ← → ← → B A` on your keyboard for inverted existential rainbow chaos.
- **Zero Cookies (Literally)**: Includes an interactive mock cookie alert you can eat. Twice.
- **Leave-Tab Guilt Trip**: Dynamic document title changes when switching browser tabs.

---

## 🛠 Tech Stack

- **HTML5**: Semantic tags, accessible attributes, and unapologetic markup.
- **Vanilla CSS3**: Neo-brutalist aesthetics, hard shadows (`box-shadow: 6px 6px 0 #1d1033`), Google Fonts (`Bowlby One`, `Space Grotesk`, `Caveat`), and responsive design.
- **Vanilla JavaScript (ES6+)**: Zero framework baggage, native `IntersectionObserver`, and micro-interactions.

## 🚀 Quick Start / Local Setup

No `npm install`, no 500MB `node_modules`, no webpack config headaches.

### Option 1: Just Open in Browser
Double click `index.html` or open directly in Chrome/Edge/Firefox/Safari.

### Option 2: Run a Local Server

Using Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

Using Node / npx:
```bash
npx serve .
```
